# Jomhor · جمهور

Ticketing and fan platform built for Morocco. First customer: a football club.

Start with `CLAUDE.md` (project brief for Claude Code), then `docs/` and `design/`.

```
CLAUDE.md                      brief, stack, non-negotiables, conventions
claude-project.md              description + custom instructions for the Claude project
docs/00-product.md             positioning, V1 in lots, open questions
docs/01-architecture.md        components, flows (mermaid)
docs/02-gate-validation-and-data-model.md   normative protocol spec
docs/03-schema.sql             PostgreSQL DDL draft
docs/04-api.md                 fan / organizer / gate API contracts, token layout
docs/05-scanner-sqlite.sql     scanner-side schema
docs/06-glossary.md            FR/AR/EN terms, result codes
design/BRAND.md                brand: logo idea, files, colours, rules
design/logo/                   SVG + PNG logo variants, app icons, favicons
design/DESIGN.md               design system + per-screen specs
design/tokens.json             design tokens
design/mockups/html/index.html ten screens, open in a browser
```
